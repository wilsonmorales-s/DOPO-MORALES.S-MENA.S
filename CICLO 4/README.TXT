PROYECTO: slotMachine (Proyecto inicial DOPO 2026-2, ciclo 4)
AUTORES: Samuel Mena Serrato, Wilson Morales Sanchez

COMO USARLO:
- Abrir esta carpeta en BlueJ (Project > Open Project).
- Para crear una maquina: new SlotMachine() o new SlotMachine(n).
- Para verla: makeVisible().
- Para resolverla: SlotMachineContest.solve(n) o SlotMachineContest.simulate(n).

TIPOS (ciclo 4):
- Ruedas: "normal", "lefty", "rebel", "lazy"   -> addWheel(type, pos)
- Simbolos: "normal", "ephemeral", "shy"       -> addSymbol(type, pos, color)

PRUEBAS:
- Ciclo 2: SlotMachineC2Test, SlotMachineCC2Test
- Ciclo 3: SlotMachineContestTest, SlotMachineContestCTest
- Ciclo 4: SlotMachineC4Test, SlotMachineCC4Test
- Clic derecho sobre la clase de prueba > Test All.
